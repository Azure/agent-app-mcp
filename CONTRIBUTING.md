# Contributing

Create a focused feature branch from `develop` and open your pull request
against `develop`. Only `release/X.Y.Z` branches in this repository may open
pull requests against `main`.

Include a short description of the change, relevant tests and results, and
documentation updates when needed. Link related issues and describe any
dependencies on changes in other repositories.

The quality gate runs automatically on pull requests and must pass before
merge. Automated checks support manual review; they do not replace it.

## Code of conduct and CLA

This project follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
See the [FAQ](https://opensource.microsoft.com/codeofconduct/faq/) or contact
[opencode@microsoft.com](mailto:opencode@microsoft.com) with questions.

Contributions may require a [Microsoft Contributor License Agreement](https://cla.opensource.microsoft.com)
(CLA) confirming that you have the right to grant permission to use your
contribution. The CLA bot will guide you when you open a pull request.
